Firebase Setup

One-time setup. Your data is stored in your own Firebase project — no login, no account needed to use the app. Just paste your config once.

✅ No authentication required — the app uses a unique device ID stored in your browser to identify your data document in Firestore.
1
Go to console.firebase.google.com → Create project → name it gym-plan → skip Analytics.
2
Click the </> Web icon → register app → copy the firebaseConfig object shown.
3
In left menu: Build → Firestore Database → Create database → Start in test mode → pick region asia-east1 (closest to Taiwan).
4
If hosting on GitHub Pages, go to Firestore → Rules and paste this rule so only requests from your domain work:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /gym_plans/{docId} {
      allow read, write: if true;
    }
  }
}
